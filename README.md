# Portfolio Manager (MERN Stack)

Sistem pengurusan portfolio ringkas yang membolehkan pengguna menambah dan memadam projek. Dibina untuk demonstrasi kebolehan Full Stack Development.

🔗 **Live Demo:** [Letak Link Vercel Awak Di Sini]

## 🛠 Tech Stack
- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** MongoDB Atlas
- **Deployment:** Vercel (FE) & Render (BE)

## 🚀 Features
- Tambah projek baru ke database.
- Papar senarai projek secara real-time.
- Padam projek dari database.
- Responsive design (Mobile & Desktop).

## 📦 Cara Install (Local)
1. Clone repo ini.
2. `npm install` di root dan folder client.
3. Setup fail `.env` dengan `MONGO_URI`.
4. `npm run dev` untuk mula.
